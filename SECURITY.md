# Security Policy

## Supported Versions

OpticsLab is in active early development. Security patches and fixes are provided for the latest main branch:

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability or numerical safety issue in OpticsLab, please do not file a public issue.

Instead, please report it via private email to:
**alexandrucrisan.dev@gmail.com**

Please include:
1. A clear description of the vulnerability or flaw.
2. Reproduction steps or a minimal test case demonstrating the issue.
3. Impact assessment (e.g. out-of-bounds GPU buffer access, denial of service via unbounded loop, invalid memory access).

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
